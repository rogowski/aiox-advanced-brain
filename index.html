[01]Contrato

O que é — e o que não é

Este repositório é a biblioteca + o cérebro de estudo. O projeto seu é onde a execução acontece.

É

Vault de curso (Markdown + wikilinks), 67 skills e 24 squads para copiar, roteador de missão e material com gates. O curso termina no artefato que funciona, não no consumo de aulas.

Não é

Não instala o AIOX inteiro. Não é o produto Enterprise. Skill no catálogo não significa execução autônoma — leia a maturidade em catalog.json antes de prometer run.

[07]Próximo passo verificável

Como começar

Abra a raiz como vault no Obsidian. Não transfira o acervo inteiro para o projeto — leve um Context Brief + o menor asset.

  1. 01
    Diagnóstico de trilha Abra cursos/COMO-ESTUDAR.md e escolha estudar ou diagnosticar cada etapa do núcleo.
  2. 02
    Primeira evidência Se o vault é novo: Obsidian + IA. Se termos técnicos travam: Arquitetura. Se já lê sistemas: Fundamentals.
  3. 03
    Missão operacional Skill isolada se bastar. Squad se a missão pedir vários especialistas. Confirme maturidade em catalog.json.
  4. 04
    Handoff Context Brief → copiar skills/<id> ou squads/<id> para o projeto → validar artefato → devolver aprendizado em notas/.
